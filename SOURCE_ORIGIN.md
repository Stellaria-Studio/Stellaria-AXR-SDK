# Source provenance

This independent SDK was extracted from `AXR/` in
[666Dean/Wechat-MCP](https://github.com/666Dean/Wechat-MCP), source commit
[`af3bec927a651e2bbb7d77b2d2e7924a606fd708`](https://github.com/666Dean/Wechat-MCP/tree/af3bec927a651e2bbb7d77b2d2e7924a606fd708/AXR).
The original source was published under AGPL-3.0-only. Existing AGPL grants remain valid.

Historical SDK contributions are credited to Minsawa, 666Dean and the Codex-labelled
commits recorded in that upstream history. Third-party notices are preserved.
The current rights holder confirmed its rights to offer the SDK-owned source under
the additional SCL path for this extraction. The new CLA is not treated as a
retroactive transfer of historical contributions.

The repository starts with an SDK-only snapshot, rather than publishing the
integration repository's unrelated history or local data. Application handlers,
chat databases, credentials, packaged third-party applications and build outputs
were not imported. Generic test sources copied from the integration preserve MIT
notices and their original license text.

Subsequent changes in this extraction include independent documentation, legal
source records, portable build/install validation and the Guard transaction/lookup
improvements recorded in CHANGELOG.md.
